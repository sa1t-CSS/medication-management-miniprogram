# 医疗健康与用药管理微信小程序

使用微信原生技术开发的个人项目，围绕用药计划、日历与医嘱记录组织日常用药信息。

## 技术栈

WXML / WXSS / JavaScript / 微信 API / 蓝牙 BLE。

## 已实现功能

- 用药计划增删改查，早晨、中午、晚上分时段查看。
- 用药日历标记与指定日期详情。
- 医嘱记录管理及与用药计划联动。
- 拍照录入入口、紧急联系人保存与快捷拨打、日历提醒接口。
- BLE 设备搜索、连接与服务发现。

## 导入运行

1. 使用微信开发者工具导入仓库根目录，项目类型选择小程序。
2. 将 `project.config.json` 中的 `your-appid` 替换为自己有权限使用的小程序 AppID；此仓库没有包含账号凭据。
3. 编译并检查首页、医嘱、我的页面。
4. 相机、电话、系统日历、蓝牙能力需要在真机上验证，并按提示授予权限。BLE 联调还需要兼容设备。

这是原生小程序，无 npm 构建步骤。业务数据主要存储于微信本地存储，仓库不包含用户的实际用药记录。

## 目录

| 路径 | 内容 |

## 当前边界

药品图片识别预留了 `registerImageRecognizer` 接口，默认未接入真实模型/OCR 服务；拍照入口不等于已经实现自动药品识别。`pages/smart` 为未注册的历史页面。蓝牙目前覆盖连接和服务发现，不宣称完成特定设备的用药控制协议。

本项目用于信息记录与提醒，不提供诊断或个体化处方建议。审核与备案信息属于原小程序主体，克隆源码不继承其审核、备案或发布权限。
